# tiktok-story-skills

Bộ skill tiếng Việt cho agent: viết story short-form TikTok (storytime) từ ý
tưởng → hook → script → kiểm retention → caption.

> Repo đang trong quá trình build. Nội dung skill, script validate và ví dụ nằm
> trên branch `feat/skills-v1`; `main` chỉ có khung repo.

## Nội dung dự kiến

5 skill, chạy theo thứ tự:

1. `story-core` — khung story + retention, một ý một video, budget thời gian.
2. `hook-writer` — viết hook và 5 biến thể khác archetype để test.
3. `tiktok-native` — FYP, sound, TikTok như search engine, production doc.
4. `vi-voice` — quy tắc tiếng Việt: nhịp câu, khẩu ngữ, xưng hô, tránh văn dịch.
5. `story-deslop` — bắt văn AI tiếng Việt, checker zero dependency.
